About Saarthi

Saarthi is an English-to-Hindi neural machine translation project built with PyTorch and SentencePiece.

This interface is a preview while the translation model is being trained.

Settings

Help & Feedback

Use Quick Phrases for built-in verified example translations. New text needs a trained model and a connected inference API.
